## Time extensions

Ordinary resume preserves saved cumulative limits. An explicit additional working-time allocation is recorded in `time_extensions`; token and request ceilings remain unchanged. The interface labels the extra minutes before sending that request. The terminal accepts `--resume-add-seconds` for `/research-resume`.

## Deliberate limits and retained compatibility

- TeX `input`/`include` expansion with a cross-file line map is not implemented. Unresolved inputs are identified in the report and force partial/provisional coverage; bibliography files can be loaded. The review does not claim to have checked omitted source text.
- The audit's bulk test-deletion and legacy-router deletion suggestions were not applied indiscriminately. Compatibility code and useful regression coverage remain. The live-network test and timing-sensitive SSE waits were repaired, and new behavioral regressions were added.
- Frozen deployment-lock provenance was not rewritten merely to update historical prose. Runtime and user documentation describe the current sequential proof controller.
- Search evidence and model reviews remain fallible. This change was validated with scripted providers, local HTTP/SSE fixtures and browser fixtures. No live model server was available during this run, so the audit's original 27B scenarios were not rerun against that model.
