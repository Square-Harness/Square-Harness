# Style guidelines: exam

- X1 [required] Header. Course, date, duration and the instructions (documents, calculators) are at the top, once.
- X2 [required] Points. Every question carries its points; the points of an exercise add up to its total, and the totals to
  the total of the exam.
- X3 [style] Independence. The text says which exercises are independent; a question that needs an earlier one says
  which, and gives the earlier result so that it can be admitted.
- X4 [style] Questions. Each question asks for one thing, with an unambiguous verb (prove, compute, determine, deduce,
  give an example). "State" or "recall" is used only for a definition or a theorem of the course that the sheet does
  not print.
- X5 [required] Notation. The notation and conventions the exercises use are fixed before them. A result of the course
  is not reprinted: students are expected to know the course. The only exception is a result a question uses whose
  exact form students cannot be expected to remember, and no question then asks to state or prove it.
- X6 [style] No solution and no hint beyond what the request asks for. A value or formula to establish, given in the
  question so that later questions can use it ("show that the sum equals $\pi^2/6$"), is not a hint.
- X7 [style] Feasibility. The length fits the duration; no question needs a result outside the course material.
- X8 [reader] Nothing given away. No question asks for something the sheet prints (a definition, a statement, a formula
  recalled), and no question asks to prove a result the sheet allows to admit.
- X9 [reader] Progression. In each exercise the questions build on each other, from a direct application of the course
  to the harder ones. Points follow the work required: none for copying, few for a one-line answer.
- X10 [reader] Doable. Each question can be answered from the course and the earlier questions, and is a real
  mathematical task (a computation, a proof, an example), not a request to repeat the course.
