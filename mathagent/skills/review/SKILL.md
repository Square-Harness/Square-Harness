# Review a manuscript

Use Review when the user asks for a mathematical review of a whole paper.
Pass the pinned manuscript and the user's requested focus to Review. Two
independent readers examine the same paper and question. A final reader checks
their findings against the manuscript and writes the pre-submission report for
the author. The readers can verify individual references when the online
settings allow it.

A request to compare the results with prior work also calls for a
literature review. The Assistant handles that request separately.
