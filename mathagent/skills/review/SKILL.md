# Review a manuscript

Use Review when the user asks for a mathematical review of a whole paper.
Pass the pinned manuscript and the user's requested focus to Review. The
main referee writes a pre-submission report for the author covering the
main results, proofs, presentation and bibliographic support. The Review
runner manages its independent challenger and source-linked notebook.
The referee can consult individual references when the online settings
allow it.

A request to compare the results with prior work also calls for a
literature review. The Assistant handles that request separately.
